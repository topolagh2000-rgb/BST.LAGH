PUBLICATION FINALE
Le site est techniquement prêt à être publié. La mise en ligne réelle de WWW.BST-HP.COM nécessite l'accès au compte qui détient le nom de domaine et à l'hébergement/DNS. Sans ces accès, aucun système ne peut modifier publiquement le domaine à votre place.

PROCÉDURE
1. Créer/ouvrir l'hébergement web.
2. Pointer le DNS de BST-HP.COM vers l'hébergement.
3. Envoyer tous les fichiers de ce dossier dans public_html ou www.
4. Activer HTTPS/SSL.
5. Tester WWW.BST-HP.COM et les liens téléphone/email.
